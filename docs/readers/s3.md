# duckport_read_s3

```sql
SELECT * FROM duckport_read_s3('s3://bucket/people.parquet', format := 'parquet', storage_options := '{"region":"us-east-1"}');
```

Reads an S3 object. `format` is required and must be included in this checkout. Use `storage_options` for region, endpoint, and other OpenDAL settings.

For CSV/TSV, pass `header`; for XML, pass `record_path`. The corresponding format PR must be merged first.

See [shared settings](../../README.md#shared-settings) and [test instructions](../../test/README.md).
